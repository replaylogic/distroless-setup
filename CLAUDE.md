# Repository instructions

Do not add AI/tool attribution to Git commits or pull request descriptions.

In particular, do not add:
- `Co-Authored-By: Claude ...`
- `Generated with Claude Code`
- `Claude-Session: ...`
- equivalent Anthropic/Claude attribution trailers

Commits should use the configured human Git author only.

Claude attribution is intentionally disabled for this repository through
`.claude/settings.json`.
